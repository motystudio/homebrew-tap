# Moty Studio Homebrew tap

```bash
brew trust motystudio/tap
brew install --cask motystudio/tap/<app>
```

Recent Homebrew versions only load casks from third-party taps you trust, hence the first line.

| Cask | App |
|---|---|
| `simlease` | [SimLease](https://github.com/motystudio/SimLease): share iOS simulators and Android emulators between parallel Claude Code sessions |
